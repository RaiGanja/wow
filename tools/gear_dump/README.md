# Экипировка до 30 уровня из клиента Forever

Замена временных данных вкладки «Экипировка 13–30» после старта. Работает только через игровое API аддонов, ничего никуда не отправляет.

1. Скопировать папку `GabellaGear` в `C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns\`.
2. В списке аддонов включить «Загружать устаревшие» (номер интерфейса Forever заранее неизвестен).
3. Любым персонажем в городе набрать `/ggd scan` и подождать сообщение «scan done» (около минуты). Ещё раз с английским текстом клиента (Battle.net → настройки игры → язык текста English): английские названия и строки «Equip:» нужны для разбора.
4. Источники копятся сами, пока аддон включён: добыча боссов в подземельях (труп босса в цели), награды в окне квеста, рецепты в открытом окне профессии.
5. Выйти из игры. Файл `_forever_\WTF\Account\<аккаунт>\SavedVariables\GabellaGear.lua` отдать в
   `python tools/gear_import.py --addon <файл>` → `data/gear30.json` (provenance `client-dump`), затем `python build.py`.

Что отдаёт клиент: ID, название на языке клиента, ячейка, уровень предмета, требуемый уровень, качество, тип брони/оружия, статы (`GetItemStats` и строки «Equip:» подсказки).
Чего клиент не отдаёт: полный лут боссов и список наград всех квестов. Источник есть только у того, что аддон видел в игре; у остального в таблице «—».
Подбор под спек делает `gear_import.py` по приоритету статов спека (`content/spec_cheats.py`, `STATS`) и типу брони и оружия класса.
